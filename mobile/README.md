# اپ واقعی گلستان شادی

این پوشه یک اپ React Native است، نه پوستهٔ وب. هر صفحه با کامپوننت بومی ساخته شده و به همان API سایت وصل می‌شود.

## الان چیست

- ورود با کد ملی و رمز
- خانه، اطلاعیه‌ها، تقویم، حضور، شهریه، امتحان و کارنامه
- نوار پایین برای جابه‌جایی

همهٔ این‌ها صفحهٔ بومی‌اند و از API سایت می‌خوانند.

## هنوز باید ساخته شود

حضور و غیاب، اطلاعیه‌ها، تقویم، شهریه، کارنامه، ثبت‌نام، و اعلان. این‌ها صفحهٔ جدا می‌گیرند، نه وب‌ویو.

## اجرا برای تست قبل از دامنه

سایت را روی رایانه بالا بیاورید (`npm run dev` در پوشهٔ اصلی)، بعد:

```bash
cd mobile
npm install
npx expo start
```

در شبیه‌ساز اندروید، آدرس پیش‌فرض `http://10.0.2.2:8080` است. روی گوشی واقعی:

```bash
EXPO_PUBLIC_API_URL=http://192.168.1.20:8080 npx expo start
```

`192.168.1.20` را با IP رایانه عوض کنید. گوشی و رایانه باید روی یک وای‌فای باشند.
