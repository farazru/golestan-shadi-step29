# گلستان شادی

سامانه مدرسه: پیش‌دبستان مختلط، دبستان دخترانه، زبانکده انگلیسی — شهر جدید سهند.

Next.js + SQLite (فایل `data/school.db`) + Better Auth. کلاس زنده با **الوکام**.

## روی رایانه دفتر

```bash
npm install
cp .env.example .env.local
# BETTER_AUTH_SECRET را با openssl rand -base64 32 پر کنید
npx drizzle-kit push
npm run dev
```

ورود با **کد ملی ۱۰ رقمی**. دانش‌آموز بعد از ثبت‌نام پرونده را کامل می‌کند.

## روی سرور (لیارا / پارس‌پک / ایران‌سرور)

۱. دامنه مثلاً `golestanshadi.ir`  
۲. سرور ابری لینوکس، حدود ۴ گیگ رم، اوبونتو  
۳. مراحل: [deploy/vps.md](deploy/vps.md)

دانش‌آموزان، نمرات و شهریه داخل `data/school.db` روی همان دیسک است. هر هفته از داشبورد مدیر نسخه پشتیبان بگیرید.

روی Vercel نگذارید — فایل SQLite آنجا ماندگار نیست.

## نقش‌ها

| نقش | چه می‌بیند |
|---|---|
| دانش‌آموز | کلاس امروز، تکالیف، اطلاعیه، حضور، شهریه (فقط مشاهده) |
| ولی | همان پرونده فرزند، بدون ورود به کلاس زنده |
| معلم | دوره‌های خودش، حضور، نمره، لینک الوکام |
| معاون | حضور، پرونده ناقص، کارنامه، پیوند ولی |
| مدیر | همه دفتر، دعوت، شهریه، آلبوم، خبر |

کلاس زنده: معلم لینک الوکام را روی دوره می‌گذارد. دانش‌آموز «ورود به کلاس الوکام» می‌زند.
